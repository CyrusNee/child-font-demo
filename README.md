# 儿童识字小报生成器

一个简单易用的 Web 应用，用于自动生成适合 5-9 岁儿童的识字小报。

## 功能特点

- 🎨 自动生成 AI 绘图提示词
- 📝 预设多个常见主题词汇库（超市、医院、公园、学校等）
- 🖼️ 调用 Nano Banana Pro API 生成高质量图片
- 💾 本地存储 API 密钥，无需重复输入
- 📋 一键复制提示词
- ⬇️ 下载生成的图片

## 使用方法

### 1. 获取 API 密钥

访问 [Kie AI API Key 管理页面](https://kie.ai/api-key) 获取您的 API 密钥。

### 2. 打开应用

直接在浏览器中打开 `index.html` 文件即可使用。

### 3. 生成小报

1. 输入主题/场景（例如：超市、医院、公园）
2. 输入小报标题（例如：《走进超市》）
3. 输入 API 密钥（首次输入后会自动保存）
4. 点击"生成小报"按钮
5. 等待图片生成完成（通常需要 1-3 分钟）
6. 查看和下载生成的图片

### 自然场景
- 花园 - 《美丽花园》

### 其他主题
- 交通 - 《交通工具》

每个主题都包含：

- 所有词汇都包含拼音（带声调）+ 汉字

如果输入其他主题，系统会使用通用词汇库。

## 注意事项

1. **API 密钥安全**：API 密钥保存在浏览器的 localStorage 中，请勿在公共电脑上使用。
2. **生成时间**：图片生成通常需要 1-3 分钟，请耐心等待。
3. **网络连接**：需要稳定的网络连接才能调用 API。
4. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Edge）。

## 常见问题

### Q: 为什么生成失败？

A: 可能的原因：
- API 密钥无效或过期
- 网络连接问题
- API 服务暂时不可用
- 账户余额不足

### Q: 可以添加自定义主题吗？

A: 可以。打开 `js/vocabulary.js` 文件，按照现有格式添加新的主题词汇即可。

### Q: 生成的图片可以商用吗？

A: 请参考 Nano Banana Pro API 的使用条款。
